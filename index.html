YouTube Loader

Пакетная автоматическая загрузка видео на YouTube по ссылке

Настройки интеграции Google

Для работы сайта необходимо создать OAuth Client ID в Google Cloud Console и включить YouTube Data API v3. Не забудьте добавить текущий URL в Authorized JavaScript Origins.

Авторизация Google

Войдите через Google, чтобы предоставить приложению доступ к загрузке видео на ваш YouTube канал.

Как начать работу:

  1. Нажмите шестеренку сверху справа и введите ваш OAuth Client ID.
  2. Нажмите кнопку Войти через Google и разрешите доступ.
  3. Перетащите видео в зону загрузки справа.
  4. Задайте нужное имя.
  5. Нажмите кнопку Запустить загрузку.
